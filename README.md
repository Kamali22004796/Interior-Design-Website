# Interior Design Website

A modern and responsive **Interior Design Website** built using frontend technologies.  
The website showcases interior design services, featured projects, design ideas, and contact information through a clean and attractive user interface.

## Live Demo

https://kamali22004796.github.io/Interior-Design-Website/

## About the Project

This project is a frontend-based interior design website created to present interior design services and projects in a professional and visually appealing way.

The website focuses on a clean layout, responsive design, attractive sections, and easy navigation to provide a smooth user experience across different devices.

## Features

-  Modern and attractive homepage
-  Interior design services section
-  Featured projects/designs section
-  Responsive design for mobile, tablet, and desktop
-  About section
-  Contact section
-  Social media links
-  Easy navigation
-  Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
