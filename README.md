# Interior-Design-Website
A modern and responsive Interior Design Website developed using frontend technologies. The website showcases creative interior designs, services, projects, and design ideas through a clean and user-friendly interface.
# Project Overview

The Interior Design Website is a frontend-based project created to demonstrate my skills in HTML, CSS, and JavaScript.

The website focuses on creating a clean, visually appealing interface for an interior design business. It presents different interior design concepts and services through a structured and responsive layout.

The project helped me practice important frontend development concepts such as web page structure, responsive design, styling, layouts, navigation, images, buttons, and JavaScript interactions.

# Objectives

The main objectives of this project are:

Create a professional interior design website.
Build a clean and attractive user interface.
Display interior design projects and services.
Create a responsive layout for different screen sizes.
Practice HTML semantic structure.
Improve CSS styling and layout skills.
Add basic interactivity using JavaScript.
Understand how different frontend technologies work together.
